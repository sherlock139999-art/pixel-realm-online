# 像素冒險世界 Online — 第一階段

原創 2D 多人即時戰鬥原型：共享地圖、虛擬搖桿、WASD、怪物、自動攻擊、範圍技能、經驗值與升級。

## 執行（電腦或雲端 Node.js 主機）

需要 Node.js 20+：

```bash
npm install
npm start
```

瀏覽 `http://localhost:3000`。同一 Wi-Fi 下，手機可透過電腦區網 IP 的 `http://IP:3000` 進入（需允許防火牆連線）。兩個瀏覽器分頁或兩支手機同時進入即可測試即時多人。

## 部署

將整個專案上傳至支援 Node.js WebSocket 的主機，執行 `npm install`，啟動命令 `npm start`，設定公開 HTTPS 網址；主機必須支援 WebSocket 升級。此專案不適用於純靜態網頁託管。

## 目前限制

本版**尚無帳號註冊、永久存檔、背包或交易**。角色資料只存在伺服器記憶體，斷線或重啟會遺失。伺服器為單一程序，尚未做負載均衡、反作弊完整驗證、持久化、資料庫或身分驗證。此版適合原型測試，不應直接當作正式營運服務。
